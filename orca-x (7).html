Reply is speaking in the wrong language? Fix voices
Spoken replies use your device's installed text-to-speech voices, not this app. If no voice exists for the language you picked, the browser silently falls back to English.

Windows: Settings → Time & Language → Speech → "Manage voices" → Add a voice → pick your language (e.g. Tamil).
macOS: System Settings → Accessibility → Spoken Content → System Voice → Manage Voices → download the language.
Android/Chrome: Settings → Accessibility → Text-to-speech output → install voice data for that language.

After installing, reopen this page (voices only refresh on load).
